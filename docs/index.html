규칙

외울 게 세 줄뿐입니다

루트 폴더 안의 폴더
──▸
보드 board
보드 폴더 안의 폴더
──▸
컬럼 column
그 안의 북마크
──▸
카드 card

폴더를 만들면 보드가 생기고, 카드를 옮기면 북마크가 옮겨집니다. 확장을 지워도 정리한 결과는 북마크에 그대로 남습니다.

기능

새 탭에서 끝내는 것들

담기
툴바 버튼을 누르면 지금 보고 있는 탭이 카드로 들어갑니다.
옮기기
카드와 컬럼을 드래그해 정렬합니다. 화면만 바뀌는 게 아니라 북마크가 실제로 이동합니다.
고치기
보드와 카드의 이름·아이콘을 제자리에서 편집합니다. 사이트 파비콘은 자동으로 붙습니다.
넘나들기
사이드바로 보드를 전환하고, 접어두면 왼쪽 가장자리에 마우스를 대는 것만으로 목록이 나옵니다.
테마
Tokyo Night 라이트·다크. 전환은 클릭한 지점에서 원형으로 번집니다.

설치

직접 빌드해서 올립니다

01

저장소를 받습니다

$ git clone https://github.com/no-jam92/kanban-bookmarks.git
$ cd kanban-bookmarks
02

빌드합니다

$ npm ci && npm run build
03

Chrome에 올립니다

chrome://extensions 에서 개발자 모드를 켜고, 압축해제된 확장 프로그램 로드로 dist/ 폴더를 선택합니다.

04

루트 폴더를 지정합니다

옵션 페이지에서 보드로 쓸 북마크 폴더를 하나 고릅니다. 그다음부터는 새 탭이 그 폴더입니다.

컴퓨터 두 대에서 쓰기

각 컴퓨터에서 위 과정을 그대로 반복하면 됩니다. 두 Chrome이 같은 Google 계정으로 로그인돼 있어야 데이터가 붙습니다.

보드·컬럼·카드는 Chrome 북마크 동기화를, 테마와 커스텀 아이콘은 chrome.storage.sync를 탑니다.

manifest.config.ts 의 key 는 지우지 마세요. 확장 ID가 거기서 나오고, ID가 바뀌면 설정이 초기화됩니다.
